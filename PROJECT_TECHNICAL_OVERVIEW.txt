PORTFOLIO WEB - RINGKASAN TEKNIS SEDERHANA
==========================================

Lokasi proyek:
C:\Users\ASUS\Documents\GitHub\portfolio-web


1. GAMBARAN UMUM
----------------

Proyek ini adalah website portfolio full-stack.

Strukturnya dibagi menjadi dua bagian utama:

- frontend-react
  Aplikasi front-end berbasis React dan Vite.

- backend-dotnet
  Aplikasi back-end berbasis ASP.NET Core Web API.

Front-end menampilkan halaman portfolio, about, contact, dan daftar project.
Back-end menyediakan API untuk mengambil data portfolio dan menerima pesan dari contact form.


2. TECH STACK UTAMA
-------------------

Front-end:

- React 19
- Vite 6
- JavaScript / JSX
- Bootstrap 5
- React Router DOM
- Axios
- ESLint

Back-end:

- ASP.NET Core 8 Web API
- C#
- Entity Framework Core
- Pomelo EntityFrameworkCore MySQL Provider
- Swagger / Swashbuckle
- MailKit untuk SMTP email

Database:

- MariaDB / MySQL
- Disarankan memakai XAMPP
- Database default bernama portfolio_web


3. STRUKTUR FOLDER

8. CARA SETUP PERTAMA KALI
--------------------------

Buka PowerShell, lalu masuk ke folder proyek:

cd C:\Users\ASUS\Documents\GitHub\portfolio-web


Install dependency front-end:

cd frontend-react
npm.cmd install


Buat file environment front-end:

Copy-Item .env.example .env


Isi default .env:

VITE_API_BASE_URL=http://localhost:5050


Restore dan build back-end:

cd ..\backend-dotnet
dotnet restore
dotnet build


9. SETUP DATABASE
-----------------

1. Buka XAMPP Control Panel.
2. Start MySQL.
3. Start Apache jika ingin memakai phpMyAdmin.
4. Buka:

   http://localhost/phpmyadmin

5. Import file:

   C:\Users\ASUS\Documents\GitHub\portfolio-web\backend-dotnet\database\portfolio_web.sql

Alternatif:

Jalankan saja back-end.
Jika MySQL aktif, back-end akan mencoba membuat database dan seed data secara otomatis.

11. ENDPOINT API UTAMA
----------------------

GET /api/portfolio

Mengambil semua data portfolio.


GET /api/portfolio/projects

Mengambil daftar project.


GET /api/portfolio/projects/{projectId}

Mengambil detail project berdasarkan projectId.


POST /api/contact

Menerima pesan dari contact form.
Pesan akan disimpan ke tabel contact_submissions.
Jika SMTP dikonfigurasi, pesan juga bisa dikirim ke email.


12. CATATAN PENTING
-------------------

- Front-end tetap bisa tampil walaupun back-end atau database mati.
  Hal ini karena ada data fallback lokal di src/data/portfolioData.js.

- Contact form membutuhkan back-end dan database agar pesan bisa tersimpan.

- Pengiriman email lewat contact form membutuhkan konfigurasi SMTP.

- Di PowerShell Windows, gunakan npm.cmd, bukan npm, jika terkena masalah execution policy.

- File backend-dotnet.http masih mengarah ke contoh /weatherforecast.
  Endpoint itu tidak ada di proyek ini.
  Untuk testing API, lebih baik gunakan Swagger.
